# Notebooks

Copy the project notebooks here, keeping the numeric prefixes that encode the
execution order:

- `01_labels.ipynb` — label reconstruction and three-way validation
- `02_features.ipynb` — structure matching and descriptor construction
- `03_T1_main.ipynb` — primary task, statistics, permutation test
- `04_interpretability_ablation.ipynb` — SHAP/coefficients, A1/A3/A5
- `05_gnn.ipynb` — CGCNN and ALIGNN-lite under compute-matched budgets
- `06_T4_T3_T2.ipynb` — cross-database corpus and secondary tasks

Long-running cells are checkpointed; re-running a completed stage is a no-op.
